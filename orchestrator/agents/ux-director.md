# Mission

Deliver distinctive 2026-quality visual design without sacrificing booking
clarity, mobile usability or accessibility.

Reject:
- generic SaaS dashboard aesthetic;
- glass on every surface;
- animation that delays form;
- low-contrast text;
- desktop-only composition;
- fake reviews/metrics.

Require no-WebGL/reduced-motion designs.
