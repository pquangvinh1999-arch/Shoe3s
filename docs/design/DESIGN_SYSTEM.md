# Wed3s Design System

Canonical colors, typography and motion are defined in `.agent/MASTER_CONTEXT.md`.

## Visual concept
“Technical cleaning lab + premium craft”: nền navy sâu, ánh cyan như quá trình làm sạch, copper như sửa chữa/phục hồi thủ công.

## Components
- Sticky header with logo, hotline, booking CTA.
- Hero 3D/fallback poster.
- Accessible before-after scrub.
- Process timeline with 3D or lightweight video/poster tiers.
- Service cards from service catalog.
- Stepper booking form.
- Trust/contact section using verified data only.

## Anti-patterns
- Glassmorphism trên mọi bề mặt.
- Autoplay camera gây chóng mặt.
- Canvas full-time rendering.
- Text quá nhỏ, CTA chồng canvas, animation không giảm được.
